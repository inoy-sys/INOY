ADEN Boulangerie 복구본 (2026-09-15)

이번 파일은 앞서 잘못 묶은 ZIP처럼 서로 다른 디자인 세트를 임의로 조립하지 않고,
대화에서 실제 사용하던 ADEN 메인 계열 HTML/CSS/JS를 기준으로 다시 맞춘 복구본입니다.

데니:
- 랜덤 눈 깜빡임
- 커피: 갖다대기 → 마시기 → 기본
- 빵: 냠 → 뿌듯/꺼억 → 기본
- 몸 클릭 반응

원본을 찾지 못한 에셋은 다른 이미지로 몰래 대체하지 않았습니다.
