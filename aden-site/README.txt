ADEN 하이브리드 홈페이지

구조
- index.html: 원페이지 메인
- menu.html: 메뉴 상세
- brand.html: 브랜드 상세
- news.html: 이벤트/뉴스 상세
- store.html: 매장 상세

기능
- 메인 상단 메뉴: 같은 index.html 안에서 스크롤 이동
- 각 섹션의 자세히 보기 버튼: 상세페이지를 새 탭으로 열기
- 상세페이지 상단 메뉴: 메인 index.html의 각 섹션으로 복귀
- MENU 상세페이지 카테고리 필터
- 모바일 햄버거 메뉴
- 스크롤 등장 효과

사용
기존 assets 폴더를 이 폴더 안에 그대로 넣으세요.


이번 수정사항
- 메인 MENU 섹션 버튼: '더 많은 메뉴 보기 →'
- 버튼 클릭 시 menu.html#all-menu을 새 탭으로 열기
- menu.html에서 대표 메뉴 4개 반복 섹션 삭제
- 상세페이지는 카테고리 필터와 전체 메뉴 목록으로 바로 이동


메뉴페이지 업데이트
- 주문 기능은 넣지 않고 메뉴북 형태로 구성
- 카테고리: NEW / SET / CROIFFEE / COFFEE / SIGNATURE DRINK / BEVERAGE / TEA / DESSERT
- 패스오더는 상단, 메뉴 히어로, 하단 CTA에서 외부 링크로 연결
- 패스오더 주소: https://app.passorder.co.kr/normal/ba97a77e-35a3-4b80-9f04-b81d6a48f42f/menus
- 현재 검색으로 확인 가능한 메뉴를 우선 반영
- 가격 확인 표시 메뉴는 추후 실제 메뉴 캡처를 기준으로 교체 권장
